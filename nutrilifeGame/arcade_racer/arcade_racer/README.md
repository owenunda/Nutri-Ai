# NutriLife — Corredor arcade

Apariencia de referencia: `nutria_game_arcade_racer.png`. Se conserva el diseño, colores, accesorios y proporciones. Ojos negros, sin blanco.

- 12 animaciones estándar más la animación exclusiva `racer_boost`.
- Cada animación: 6 cuadros PNG RGBA de 512×512, spritesheet de 3072×512, GIF de vista previa y JSON.
- El alimento no está dibujado en comer/recuperación: el juego lo muestra por separado.
- Oro y diamante: todas las acciones permanecen levitando, sin tocar el suelo.
